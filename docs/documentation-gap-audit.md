# 文档与实现对照（2026-09-26）

## 本轮继续完成的功能

- 将现有青岛社保模拟增减员 Workflow 示例和北京医保、单位参保证明结构草稿展示到工作流页；选择示例可新建 Workflow 或覆盖当前编辑中的草稿，但不会自动发布。
- 独立逐节点编辑组件支持 ID、配置 JSON、超时、可重试只读步骤的重试次数、业务动作权限及上移/下移/删除；保留原有高级 JSON。
- 服务端发布校验补充运行时必需的 `config.url/selector/path/steps`，并拒绝未替换的示例页面选择器。节点实际字段、参数注入和回归步骤详见 [工作流节点手册](rpa-workflow.md)。

接下来应依次实现专用节点字段表单与结构化 Extract 结果，随后验证下载产物的远程持久化和跨客户隔离；UKey/验证码、组织租户、多实例高可用仍是独立的大项，不能因为模板可展示就标记已完成。
