# 前端要求对照与验收范围

对照 [UI 要求](ui-requirements.md) 维护。标记“进行中”的条目仍需开发，不能因页面能打开就认定符合需求。

| 要求 | 当前实现与验收 | 状态 |
| --- | --- | --- |
| 登录与 Windows 开发 | Vite 代理统一到 `127.0.0.1:5000`；登录使用统一 API 模块；重载验证 `/auth/me`，失效会话清理；详见 [Windows 调试说明](windows-development.md)；CI 浏览器用例覆盖登录和所有菜单入口。 | 已实现基础链路 |
| Light / Dark 与自定义主题 | Design Token、主/辅色、背景、卡片、圆角、阴影、密度、动效、科技强度均支持本地保存；浏览器用例验证持久化。 | 已实现基础配置；业务页面旧样式待逐页清理 |
| 多语言 | `common/system/task/workflow/permission/audit/usage/theme` 资源按模块分开；登录、工作台、任务列表、审计、用量、主题设置及通用表单/表格使用 key；JSON 语言包可导入且存在本地。 | 进行中：其余业务页面仍有硬编码文本，完整英文和自定义语言包覆盖待补 |
| 页面与 API 组件化 | 外壳布局、会话 Store、认证 API、主题 composable、查询/表格组件分文件；审计、用量、账户、节点能力复用表格，审计和用量复用查询表单。 | 进行中：其他管理页面的 API/表单/表格待迁移 |
| SearchForm | schema、查询、重置、展开、选择项、loading、响应布局已具备。 | 进行中：字段参数序列化待封装为通用 API 工具，更多页面待接入 |
| DataTable | schema、客户端分页/排序/筛选、选择、批量事件、列显示、CSV 导出、刷新、空状态和密度已具备。 | 进行中：大型数据需服务端分页/排序，批量操作需业务端接入 |
| CRUD 常用组件 | `FormDialog`、`DetailDrawer`、`ConfirmAction` 已独立实现并接入节点池重命名/删除和节点详情；账户、角色、资源已有真实接口。 | 进行中：其他管理页面的统一迁移及键盘焦点完整性验收待完成 |
| RPA 可视化 | 任务进度取自任务项数据、节点卡片取自节点心跳、Workflow Canvas 取自实际步骤定义；单次执行时间线/日志/子项表格独立组件。 | 进行中：BrowserPreview、HumanInterventionPanel 等专用组件与编辑式 Canvas 待完成 |
| 功能验证 | 原有工作台、审批、权限、真实 NodeAgent、Mock 社保的 Playwright 用例保持运行；新用例覆盖菜单/登录/会话/主题/语言。 | 进行中：每个页面的增删改、边界与移动交互需扩充 |

本表只陈述已经有证据的范围；后续改动须保持 `npm run build` 与仓库 CI 绿色。
