# 前端要求对照与验收范围

对照 [UI 要求](ui-requirements.md) 维护。标记“进行中”的条目仍需开发，不能因页面能打开就认定符合需求。

| 要求 | 当前实现与验收 | 状态 |
| --- | --- | --- |
| 登录与 Windows 开发 | Vite 默认代理到 `127.0.0.1:5000`，可通过 `VITE_API_PROXY_TARGET` 配置 8666；Development 的 HTTP API 不再跳转 HTTPS 导致跨源预检失败；登录使用统一 API 模块；重载验证 `/auth/me`，失效会话清理；详见 [Windows 调试说明](windows-development.md)；CI 浏览器用例覆盖登录和所有菜单入口。 | 已实现基础链路；用户本机 8666 尚需重启验证 |
| Light / Dark 与自定义主题 | Design Token、主/辅色、背景、卡片、圆角、阴影、密度、动效、科技强度均支持本地保存；新会话采用浅色 SaaS 默认主题，导航按业务分组；浏览器用例验证持久化。 | 已实现基础配置；业务页面旧样式待逐页清理 |
| 多语言 | `common/system/task/workflow/permission/audit/usage/theme/resources/users/nodes` 资源按模块分开；登录、工作台、任务列表、资源、节点列表与详情、账户角色、权限中心、Workflow 管理、审计、用量、主题设置及通用表单/表格使用 key；JSON 语言包可导入且存在本地。 | 进行中：其余业务页面仍有硬编码文本，完整英文和自定义语言包覆盖待补 |
| 页面与 API 组件化 | 外壳布局、会话 Store、认证/审计/用量/任务/规划/资源/权限/Workflow/账户/节点 API、主题 composable、查询/表格组件分文件；审计、用量、账户、角色、节点与槽位、节点能力、节点池、权限记录、资源地区与系统复用表格。 | 进行中：其他管理页面的 API/表单/表格待迁移 |
| SearchForm | schema、查询、重置、展开、选择项、loading、响应布局已具备。 | 进行中：字段参数序列化待封装为通用 API 工具，更多页面待接入 |
| DataTable | schema、客户端分页/排序/筛选、选择、批量事件、列显示、CSV 导出、刷新、空状态和密度已具备。 | 进行中：大型数据需服务端分页/排序，批量操作需业务端接入 |
| CRUD 常用组件 | `FormDialog`、`DetailDrawer`、`ConfirmAction` 已独立实现并接入节点池重命名/删除、资源创建、权限授权、Workflow 创建、账户与角色创建及节点详情；新增后端角色停用和用户角色撤销，自动校验管理员操作边界；工作流切换自动读取并显示当前版本，可停用并重新启用。 | 进行中：其他管理页面的统一迁移及键盘焦点完整性验收待完成 |
| RPA 可视化 | 任务进度取自任务项数据、节点卡片取自节点心跳、Workflow Canvas 取自实际步骤定义；设计器可浏览默认模板、导入草稿、逐 Step 修改 config/超时/动作权限、调整顺序；执行时间线、日志、子项表格、人工介入列表独立组件；图片产物可通过授权接口按需预览。 | 进行中：拖拽编辑式 Canvas、专用节点字段编辑、远程节点产物持久化和图片预览端到端验收待完成 |
| 功能验证 | 原有工作台、审批、权限、真实 NodeAgent、Mock 社保的 Playwright 用例保持运行；新用例覆盖菜单/登录/会话/主题/语言，以及角色分配/撤销/停用、业务系统启停、Workflow 版本切换/停用恢复及节点槽位入口。 | 进行中：每个页面的增删改、边界与移动交互仍需扩充 |

本表只陈述已经有证据的范围；后续改动须保持 `npm run build` 与仓库 CI 绿色。
